Bulle — terminal coding agent

Watch your coding agent reason, plan, and work through a full-screen terminal interface.

Go 1.26  ·  Bubble Tea v2  ·  nacelle SDK v0.26 Install

What's inside

  • Full-screen Bubble Tea v2 TUI — one model turn at a time
  • Runs against any backend nacelle ships: Anthropic, Google, OpenAI, OpenRouter
  • Read and edit files, run commands (-bash), fetch web pages, call MCP tools
  • Parallel subagents — wide searches or log dumps cost the conversation one answer
  • Project context discovery (CLAUDE.md, AGENTS.md) and agent skills into the system prompt
  • Tool approval gating with -approve-tools, hook trust with remembered decisions

Install

curl -fsSL https://raw.githubusercontent.com/FacileStudio/bulle/main/install.sh | bash

Already have facile:

facile install bulle

Or Homebrew:

brew install FacileStudio/tap/bulle
